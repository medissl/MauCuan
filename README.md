# MauCuan

A native Android and iOS app for recording income and spending, setting savings goals, and building consistent habits with Miko the spotted macan. Built with Expo / React Native and Supabase.

Current app source: **0.3.1**. Adds spatial receipt recognition, a comic dialogue bubble and more pet interactions, 68 collectibles with milestones past three years, optional habit-aware reminders, and an Android home-screen widget. See [release notes and validation](docs/release-0.3.1.md). A new native APK is required for this release. The earlier 0.3.0 build finished successfully; build history is in [Android previews](docs/android-preview.md).
