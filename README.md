# MauCuan

A native Android and iOS app for recording income and spending, setting savings goals, and building consistent habits with Miko the spotted macan. Built with Expo / React Native and Supabase.

Current app source: **0.3.3**. Repairs quiz answer controls and moves Miko's dialogue into a fixed area beneath the decorated room interior, within the same frame. Preserves the accepted receipt scanner, 68 collectibles, long-term milestones, habit reminders and Android widget. See [release notes and validation](docs/release-0.3.3.md). The finished 0.3.2 APK does not include these latest pet-section fixes; build history is in [Android previews](docs/android-preview.md).
