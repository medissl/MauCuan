# MauCuan

A native Android and iOS app for recording income and spending, setting savings goals, and building consistent habits with Miko the spotted macan. Built with Expo / React Native and Supabase.

Current app source: **0.4.0**. Daily five-question quizzes use a 500-question bank and a server-controlled leaf reward. The pet room has fixed decoration spots, dialogue-specific expressions and friendlier collection copy. Transaction history has calendar and monthly list modes. Level-gated gifts still extend beyond three years. See [release notes and validation](docs/release-0.4.0.md) and [Android preview status](docs/android-preview.md). A new APK is needed to use these changes.
