# MauCuan

A native Android and iOS app for recording income and spending, setting savings goals, and building consistent habits with Miko the spotted macan. Built with Expo / React Native and Supabase.

Current app source: **0.3.2**. Fixes two-line receipt items and gives Miko a fixed speech bubble inside her room, casual dialogue and quiz answers in a native popup. Includes the earlier 68 collectibles, long-term milestones, habit reminders and Android widget. See [release notes and validation](docs/release-0.3.2.md). The finished 0.3.1 APK does not include these latest fixes; build history is in [Android previews](docs/android-preview.md).
