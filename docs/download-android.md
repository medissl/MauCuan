# Download dan instal MauCuan

Website: https://maucuan-finance.vercel.app/#download

APK 0.4.2: https://github.com/medissl/MauCuan/releases/download/v0.4.2/MauCuan-0.4.2.apk

## Cara instal

1. Buka website MauCuan atau README GitHub di ponsel Android.
2. Ketuk **Download untuk Android**. File APK diunduh dari GitHub Releases; tidak perlu login GitHub atau Expo.
3. Buka APK dari daftar unduhan. Android mungkin meminta izin memasang aplikasi dari browser atau aplikasi file tersebut.
4. Izinkan jika kamu memang mengunduh APK resmi dari link di atas, lalu pilih **Install**. Izin sumber tersebut bisa dimatikan kembali setelah selesai.
5. Buka MauCuan, daftar dan verifikasi email, lalu isi saldo awal. Jika sudah punya akun, pilih masuk.

Jika Android menampilkan peringatan Play Protect, baca peringatannya. Jangan mematikan perlindungan sistem secara menyeluruh. Pastikan nama file dan sumber unduhan benar; hubungi bantuan jika pemasangan diblokir.

## Update

Unduh APK versi baru dari website atau GitHub Releases lalu instal sebagai pembaruan, tanpa menghapus aplikasi sebelumnya. Identitas paket dan tanda tangan aplikasi harus tetap sama agar pembaruan diterima. Data yang telah tersimpan di akun tetap berada di Supabase. Update lewat APK belum otomatis seperti Play Store.

## Untuk pemilik proyek

APK disimpan sebagai **release asset**, bukan di folder source GitHub. Tag `v0.4.2` menunjuk commit `57a030f87c754a5e7c54ff2d01a482f8e1d72dee`, sumber build Expo `2b4b94f1-8c99-4229-b47e-b0d9856a60ea` (Android build 9). Build sukses pada 7 Oktober 2026.

Untuk rilis berikutnya: selesaikan dan uji build, unduh APK, buat GitHub Release dengan tag versi dan commit build yang benar, lampirkan APK, lalu ubah link serta nomor versi pada website dan README. Gunakan nama file yang jelas seperti `MauCuan-0.4.3.apk`. Link versi tertentu memudahkan pengguna mengetahui file yang mereka instal.

APK dapat diunduh siapa pun karena repositori ini publik. Tidak perlu membuat akun toko aplikasi untuk distribusi ini. File APK tidak menjalankan aplikasi di browser; website menjadi pintu unduh, sementara aplikasi berjalan di Android.
